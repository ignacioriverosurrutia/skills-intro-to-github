# Introducción a GitHub

_Comienza a usar GitHub en menos de una hora._

## Bienvenido

Las personas usan GitHub para construir algunas de las tecnologías más avanzadas del mundo. Ya sea que estés visualizando datos o creando un nuevo juego, hay toda una comunidad y un conjunto de herramientas en GitHub que pueden ayudarte a hacerlo aún mejor. El curso "Introducción a GitHub" te guía a través de todo lo que necesitas para comenzar a contribuir en menos de una hora.

- **¿Para quién es esto?**: Nuevos desarrolladores, nuevos usuarios de GitHub y estudiantes.
- **¿Qué aprenderás?**: Introduciremos repositorios, ramas, confirmaciones (commits) y solicitudes de extracción (pull requests).
- **¿Qué construirás?**: Crearemos un archivo Markdown corto que puedes usar como tu [README de perfil](https://docs.github.com/es/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme).
- **Requisitos previos**: Ninguno. Este curso es una excelente introducción para tu primer día en GitHub.
- **Duración**: Este curso toma menos de una hora para completar.

En este curso, aprenderás a:

1. Crear una rama (branch)
2. Confirmar un archivo (commit)
3. Abrir una solicitud de extracción (pull request)
4. Fusionar tu solicitud de extracción (merge)

## Conceptos básicos de GitHub

### ¿Qué es un repositorio?

Un **repositorio** es un lugar donde se almacena tu proyecto. Puede contener carpetas y archivos, imágenes, videos, hojas de cálculo y conjuntos de datos: todo lo que tu proyecto necesite.

### ¿Qué es una rama (branch)?

Una **rama** es una versión paralela de tu repositorio. Por defecto, tu repositorio tiene una rama llamada `main`, que se considera la rama definitiva. Puedes crear ramas adicionales fuera de `main` para experimentar y hacer ediciones antes de fusionarlas en `main`.

### ¿Qué es un commit?

Un **commit** es un cambio guardado. Cada vez que haces un commit, creas un registro de los cambios que has realizado en tu repositorio. Los commits incluyen un mensaje de confirmación que describe los cambios.

### ¿Qué es una solicitud de extracción (pull request)?

Una **solicitud de extracción** es una propuesta de cambios. Cuando creas una pull request, estás proponiendo tus cambios y solicitando que alguien revise y fusione tu contribución en su rama.

## Primeros pasos

Para comenzar con GitHub:

1. **Crea una cuenta** en [github.com](https://github.com) si aún no tienes una
2. **Explora repositorios** para ver proyectos de código abierto
3. **Crea tu primer repositorio** para comenzar a experimentar
4. **Aprende Git** - el sistema de control de versiones que usa GitHub
5. **Colabora** haciendo fork de repositorios y enviando pull requests
