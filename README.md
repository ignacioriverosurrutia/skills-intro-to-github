# Introducción a GitHub

_Comienza a usar GitHub en menos de una hora._

## Bienvenido

Este repositorio es tu espacio para aprender los conceptos básicos de GitHub. Aquí aprenderás sobre repositorios, ramas, confirmaciones (commits) y solicitudes de extracción (pull requests).

## Cómo clonar este repositorio

📘 **¿Primera vez?** Lee la [Guía de Inicio Rápido](./INICIO_RAPIDO.md)

📗 **¿Problemas al clonar?** Consulta la [Guía Completa de Clonación](./GUIA_CLONACION.md)

Si estás teniendo problemas para clonar este repositorio, aquí están las instrucciones detalladas:

### Opción 1: Clonar con HTTPS

```bash
git clone https://github.com/ignacioriverosurrutia/skills-intro-to-github.git
```

### Opción 2: Clonar con SSH

Primero, asegúrate de tener configuradas tus llaves SSH en GitHub. Luego:

```bash
git clone git@github.com:ignacioriverosurrutia/skills-intro-to-github.git
```

### Opción 3: Descargar como ZIP

Si no tienes Git instalado, puedes descargar el repositorio como un archivo ZIP:

1. Haz clic en el botón verde "Code" en la parte superior de esta página
2. Selecciona "Download ZIP"
3. Extrae el archivo ZIP en tu computadora

## Requisitos previos

Para clonar este repositorio necesitas:

- **Git instalado**: Descárgalo desde [git-scm.com](https://git-scm.com/)
- **Cuenta de GitHub**: Si no tienes una, créala en [github.com](https://github.com/)

## Solución de problemas comunes

### Error: "fatal: could not read Username"

Esto significa que Git necesita tus credenciales. Asegúrate de:
- Estar conectado a internet
- Tener una cuenta de GitHub
- Usar la URL correcta del repositorio

### Error: "Permission denied (publickey)"

Si estás usando SSH, verifica que:
- Hayas generado tus llaves SSH
- Las llaves estén agregadas a tu cuenta de GitHub
- Estés usando la URL SSH correcta

### Error: "Repository not found"

Verifica que:
- La URL del repositorio sea correcta
- Tengas permisos para acceder al repositorio
- El repositorio exista y sea público (o que tengas acceso si es privado)

## Próximos pasos

Una vez que hayas clonado exitosamente el repositorio:

1. Abre el repositorio en tu editor de código favorito
2. Explora los archivos
3. Haz cambios y practica con Git
4. Crea una rama nueva para tus cambios
5. Realiza commits de tus cambios
6. Crea un pull request
